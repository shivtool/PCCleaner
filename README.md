## ज़रूरी बातें
- Windows 10 या 11 चाहिए; प्रोग्राम खुलते समय **Yes** (Administrator) दबाएँ।
- Deep Clean **Recycle Bin खाली** करता है – पहले देख लें।
- "Windows protected your PC" दिखे तो **More info → Run anyway** (सिर्फ़ भरोसेमंद स्रोत से लिए प्रोग्राम पर)।
